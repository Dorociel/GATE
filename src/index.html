    입력 안내와 제한
    • 파일은 UTF-8로 읽습니다. 다른 인코딩이면 한글 주석 등이 깨질 수 있습니다(깨진 글자가 있으면 파일 정보에 표시).
    • 파일 하나가 2MB를 넘으면 불러오지 않고, 약 30만 자를 넘으면 분석하지 못합니다.
    • 선택할 수 있는 확장자는 .v, .sv 입니다(.vh 헤더는 지원하지 않음). 폴더 전체 불러오기는 지원하지 않습니다.
    • .sv를 선택할 수 있다는 것이 SystemVerilog 문법 지원을 뜻하지 않습니다. 지원하지 않는 문법은 누락·오인식될 수 있습니다.
    • `include 대상 파일은 자동으로 찾지도 분석하지도 않습니다. 필요한 파일은 직접 추가하세요. 매크로·generate 등 파서의 한계는 그대로입니다.

    확인

    지원 문법 안내

    지원 (첫 버전)

    • module ~ endmodule 정의, 여러 모듈을 한 입력창에 붙여넣기
    • 이름 기반 포트 연결 인스턴스
      모듈명 [#(...)] 인스턴스명 (.포트(신호), ...);
    • 선언문당 인스턴스 1개, 같은 모듈의 여러 인스턴스는 각각 별도 블록
    • // 및 /* */ 주석 무시
    • 선택한 최상위 모듈 아래의 인스턴스 경로를 따라 계층 구성

    제한 (지원하지 않음)

    • generate / genvar 내부 인스턴스
    • 매크로, `ifdef, `include 등 컴파일러 지시어
    • SystemVerilog 문법 (interface, package, logic 등)
    • 게이트 프리미티브(and, or 등)는 모듈로 취급하지 않음
    • 위치 기반 포트 연결·인스턴스 배열은 관계만 인식(확인 필요)
    • 입력 코드에 정의가 없는 모듈은 ‘정의 미제공’으로 표시하고 펼치지 않음
    • 신호 연결 탭은 단일 신호명 연결만 표시(비트 선택·연산식·상수·위치 기반은 제외, 하위 계층을 관통하는 추적 없음, assign/always 구동 분석 없음). 자세한 제한은 ‘신호 연결’ 탭에서 확인
    • 저장 기능 없음

    모든 Verilog 문법을 지원하지 않습니다. 분석 후 ‘인식 결과’ 탭에서 모듈·인스턴스 목록을 코드와 대조하세요.
